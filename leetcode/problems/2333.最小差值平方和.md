这道题是一道非常经典的**贪心**问题（LeetCode 2333. 最小差值平方和）。

我们可以从**数学性质转化**、**核心贪心策略**以及**两种具体实现（二分法 vs 桶计数法）**来拆解思路。

---

### 一、核心思路与性质转化

#### 1. 操作等价性：合并 $k_1$ 和 $k_2$
设 $d_i = |nums1[i] - nums2[i]|$，我们要最小化的是 $\sum d_i^2$。
- 对 $nums1[i]$ 加 $1$，与对 $nums2[i]$ 减 $1$ 的效果完全一样，都是让两者的差值绝对值发生变化。
- 只要 $d_i > 0$，无论使用 $k_1$ 还是 $k_2$，每次操作都可以且只应该**让 $d_i$ 减小 $1$**。
- 因此，**$k_1$ 与 $k_2$ 可以直接合并为一个总操作次数 $k = k_1 + k_2$**。

#### 2. 贪心策略：为什么优先减去最大的差值？
观察数值从 $x$ 变成 $x - 1$ 时，平方差的变化量：
$$x^2 - (x - 1)^2 = 2x - 1$$
显然，**$x$ 越大，$2x - 1$ 就越大，收益也就越高**。
为了让总平方和下降得最多，我们每一次操作都应该**贪心地减小当前最大的 $d_i$**。
换句话说，我们的目标是：**“削峰填谷”——把数组中的所有大数尽量削平，让它们变得尽可能小且均匀。**

如果所有差值之和 $\sum d_i \le k$，我们可以把所有差值全变成 $0$，答案直接为 $0$。

---

### 二、解法选择

针对这种“把所有数削平”的问题，通常有两种最优解：

#### 解法 1：计数/桶模拟（最推荐，简单且快）
注意到题目数据范围：$0 \le nums1[i], nums2[i] \le 10^5$，因此差值 $d_i$ 的最大值不会超过 $M = 10^5$。
- 用一个频数数组 `cnt[v]` 记录差值为 $v$ 的元素个数。
- 从最大值 $v = 10^5$ 开始从大到小往下模拟：
  - 如果剩余的 $k \ge cnt[v]$：说明能把这 $cnt[v]$ 个数全部削低 $1$（变成 $v - 1$）。
    - $k \gets k - cnt[v]$
    - $cnt[v - 1] \gets cnt[v - 1] + cnt[v]$
  - 如果 $k < cnt[v]$：说明只能削低其中的 $k$ 个数。
    - 有 $k$ 个数变成了 $v - 1$；
    - 剩下 $cnt[v] - k$ 个数保持为 $v$；
    - $k$ 用完了，退出循环。
- **时间复杂度**：$O(n + M)$，一次线性遍历，效率极高。

#### 解法 2：二分答案（通用解法，面试官最喜欢的扩展）
如果题目把数据范围扩大到 $nums1[i] \le 10^9$，桶数组开不下，就必须用**二分查找**：
- 二分最终所有差值的**“上限” $T$**（即所有大于 $T$ 的数都被削到了 $T$）。
- `check(T)`：计算把所有大于 $T$ 的差值削到 $T$ 需要多少次操作 $\sum \max(0, d_i - T)$。若操作数 $\le k$，说明上限 $T$ 可以达到（甚至可能更小）。
- 找到最小可达的 $T$ 之后，如果还有剩余的 $k$，由于 $T$ 是下限，我们只能把一部分刚好等于 $T$ 的数进一步减成 $T - 1$。
- **时间复杂度**：$O(n \log(\max d))$。

### 三、代码实现

#### 方法一：桶计数法（针对本题最简洁代码）

```cpp
class Solution {
public:
    long long minSumSquareDiff(vector<int>& nums1, vector<int>& nums2, int k1, int k2) {
        int n = nums1.size();
        long long k = (long long)k1 + k2;
        
        int max_d = 0;
        vector<int> cnt(100001, 0);
        long long sum_d = 0;
        
        for (int i = 0; i < n; ++i) {
            int d = abs(nums1[i] - nums2[i]);
            cnt[d]++;
            max_d = max(max_d, d);
            sum_d += d;
        }
        
        // 如果操作数足以把所有差值清零
        if (sum_d <= k) return 0;
        
        // 从大到小削峰
        for (int v = max_d; v > 0; --v) {
            if (cnt[v] == 0) continue;
            
            if (k >= cnt[v]) {
                k -= cnt[v];
                cnt[v - 1] += cnt[v];
                cnt[v] = 0;
            } else {
                cnt[v] -= k;
                cnt[v - 1] += k;
                k = 0;
                break;
            }
        }
        
        // 计算平方和
        long long ans = 0;
        for (long long v = 1; v <= max_d; ++v) {
            if (cnt[v] > 0) {
                ans += (long long)cnt[v] * v * v;
            }
        }
        return ans;
    }
};
```

#### 方法二：二分答案法（通用版）

```cpp
class Solution {
public:
    long long minSumSquareDiff(vector<int>& nums1, vector<int>& nums2, int k1, int k2) {
        int n = nums1.size();
        long long k = (long long)k1 + k2;
        vector<int> d(n);
        int max_val = 0;
        long long total = 0;
        
        for (int i = 0; i < n; ++i) {
            d[i] = abs(nums1[i] - nums2[i]);
            max_val = max(max_val, d[i]);
            total += d[i];
        }
        
        if (total <= k) return 0;
        
        // 二分找最小上限 mid
        auto check = [&](int mid) -> bool {
            long long need = 0;
            for (int x : d) {
                if (x > mid) need += x - mid;
            }
            return need <= k;
        };
        
        int left = 0, right = max_val;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (check(mid)) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        
        // 削到 left 后的剩余操作数
        int limit = left;
        for (int x : d) {
            if (x > limit) k -= (x - limit);
        }
        
        // 计算最终平方和，同时用剩余的 k 把等于 limit 的数变成 limit - 1
        long long ans = 0;
        for (int x : d) {
            int cur = min(x, limit);
            if (cur == limit && k > 0 && cur > 0) {
                cur--;
                k--;
            }
            ans += 1LL * cur * cur;
        }
        
        return ans;
    }
};
```

### 四、容易踩坑的细节
1. **整数溢出**：
   - $k1 + k2$ 可能会超过 `int`，必须用 `long long`；
   - 最终平方和计算 $\sum d_i^2$ 最大可达 $10^5 \times (10^5)^2 = 10^{15}$，必须使用 `long long`。
2. **剩余操作处理**：
   - 在二分求出上限 `limit` 后，剩下的 $k$ 只能分给等于 `limit` 的元素使其变成 `limit - 1`，不能给已经小于 `limit` 的元素。
