# 2574. 左右元素和的差值

## 题目描述

给你一个下标从 0 开始的整数数组 `nums` 。请你返回一个长度与 `nums` 相等的数组 `answer` ，其中 `answer[i]` 等于 `|leftSum[i] - rightSum[i]|` 。

## 思路

设 `leftSum[i]` 是 `nums[0]` 到 `nums[i-1]` 的元素和，`rightSum[i]` 是 `nums[i+1]` 到 `nums[n-1]` 的元素和，`total` 是 `nums` 的元素和。

$$
total = sum(nums) = leftSum[i] + nums[i] + rightSum[i]
$$

$$
rightSum[i] = total - leftSum[i] - nums[i]
$$

$$
answer[i] = |leftSum[i] - rightSum[i]| = |leftSum[i] - (total - leftSum[i] - nums[i])| = |2 * leftSum[i] + nums[i] - total|
$$

因此，我们可以在每次遍历更新 `leftSum` 从而计算 `answer` 数组。

- 时间复杂度：O($n$)
- 空间复杂度：O($1$)

### 代码

```py
class Solution:
    def leftRightDifference(self, nums: List[int]) -> List[int]:
        res = []
        total = sum(nums)
        left_sum = 0
        for i in range(len(nums)):
            res.append(abs(total - 2 * left_sum - nums[i]))
            left_sum += nums[i]

        return res
```
