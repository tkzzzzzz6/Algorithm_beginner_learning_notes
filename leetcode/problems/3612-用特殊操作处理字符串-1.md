# 3612-用特殊操作处理字符串-1

# 思路: 模拟题，按照题目要求进行字符串的处理即可。
遍历字符串 s，对于每个字符 c：
- 如果 c 是 '*'，则删除 ans 中的最后一个字符（如果 ans 不为空）。
- 如果 c 是 '#'，则将 ans 中的内容重复一次。
- 如果 c 是 '%'，则将 ans 中的内容反转。
- 否则，将 c 添加到 ans 中。
- 最后，将 ans 中的字符连接成一个字符串并返回。

# 复杂度分析
- 时间复杂度: O(n)，其中 n 是字符串 s 的长度。
- 空间复杂度: O(n)，最坏情况下 ans 可能会存储整个字符串。

```py
class Solution:
    def processStr(self, s: str) -> str:
        ans = []
        for c in s:
            if c == '*':
                if ans:
                    ans.pop()
            elif c == '#':
                ans += ans
            elif c == '%':
                ans.reverse()
            else:
                ans += c
        
        return "".join(ans)
```
