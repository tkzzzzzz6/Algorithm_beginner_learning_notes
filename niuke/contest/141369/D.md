# D. 乘积等于和

## 题目描述

给定一个正整数 $n$ ，请你构造一个长度为 $n$ 的正整数数组 $a$ ，满足：  

- 数组中的所有元素都是正整数，且任意元素 $a_i$ 的值不得超过 $10^8$ ；  
- 所有元素的乘积等于所有元素的和，且这个和不得超过 $10^{18}$ 。  

输出任意一个满足条件的数组即可。题目保证一定有解。  
  


## 输入描述

一行，一个整数 $n$ （ $1 \le n \le 10^6$ ）。  


## 输出描述

输出一行 $n$ 个正整数，表示你构造的数组。  
如果有多种答案，输出任意一种即可。  


## 样例

### 样例 1
**输入**:
```
3
```

**输出**:
```
1 2 3
```

**说明**:  

$1 + 2 + 3 = 6$ ， $1 × 2 × 3 = 6$ ，满足条件。  


### 样例 2
**输入**:
```
2
```

**输出**:
```
2 2
```

**说明**:  

$2 + 2 = 4$ ， $2 × 2 = 4$ ，满足条件。
