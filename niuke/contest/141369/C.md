# C. 判断三角形

## 题目描述

输入三个正整数 $a$ 、 $b$ 、 $c$ ，表示三条边的长度。  

首先判断这三条边能否构成一个三角形：  

- 如果能构成三角形，再判断它属于哪种类型：  
- 若三边都相等，输出 “Equilateral”（等边三角形）  
- 若只有两边相等，输出 “Isosceles”（等腰三角形）  
- 若三边都不相等，输出 “Scalene”（普通三角形）  
- 如果不能构成三角形，输出 “Not a triangle”  
不需要输出引号和后面的括号。  


## 输入描述

一行三个正整数 $a$ 、 $b$ 、 $c$ （ $1 \le a,b,c \le 1000$ ），用空格隔开。  
  


## 输出描述

按题目要求输出对应的字符串。  


## 样例

### 样例 1
**输入**:
```
3 3 3
```

**输出**:
```
Equilateral
```

### 样例 2
**输入**:
```
3 3 5
```

**输出**:
```
Isosceles
```

### 样例 3
**输入**:
```
3 4 5
```

**输出**:
```
Scalene
```

### 样例 4
**输入**:
```
1 2 3
```

**输出**:
```
Not a triangle
```
