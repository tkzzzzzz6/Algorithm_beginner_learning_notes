# E. 买文具

## 题目描述

小明带了 $N$ 元钱去文具店，准备买三种文具，每种至少买 $1$ 件：  

- 钢笔每支 $5$ 元  
- 笔记本每本 $3$ 元  
- 橡皮每块 $1$ 元  

请问：一共有多少种购买方案，能正好把 $N$ 元花完？  


## 输入描述

一行一个整数 $N$ （ $1 \le N \le 200$ ），表示总钱数。  


## 输出描述

一行一个整数 $ans$ ，表示方案总数。  
  


## 样例

### 样例 1
**输入**:
```
20
```

**输出**:
```
8
```

**说明**:  

具体方案如下（依次为钢笔、笔记本、橡皮的数量）  
$1$  $1$  $12$   
$1$  $2$  $9$   
$1$  $3$  $6$   
$1$  $4$  $3$   
$2$  $1$  $7$   
$2$  $2$  $4$   
$2$  $3$  $1$   
$3$  $1$  $2$
