# C. 今州的回声消除

## 题目描述

任务简报  
今州的一台演练终端收集了 2n 枚回声符片，分成 n 类，每一类恰好出现两次，并按采集顺序排列。  

漂泊者可以选择一个仍然存在的编号，清除它最左与最右出现位置之间的整段符片。终端按本次实际清除数量的平方计分，剩余符片随即按原顺序拼接。  

研究员提醒：“先清掉中间的一段，后面能清掉的数量也会改变。”漂泊者停下手，决定先算出能获得的最大总分。这些消除与计分规则仅用于本题演练。  
题目描述  
给定长为`2n`的数组`a`，其中`1`到`n`每个整数恰好出现两次。初始得分为`0`。  

数组非空时，可以重复进行以下操作：  
- 选择一个当前仍在数组中的值`x`。
- 令`l,r`分别为`x`在当前数组中最左、最右的出现位置；若只剩一次，则`l=r`。
- 得到`(r-l+1)^2`分，然后删除当前数组中的整段`a_l,...,a_r`。
- 剩余部分按原有相对顺序拼接，并从`1`重新编号。

求把数组完全删空后能够获得的最大总分。  
  


## 输入描述

- 第一行一个整数n，1 ≤ n ≤ 2×10^5。
- 第二行2n个整数a_i，1 ≤ a_i ≤ n。
- 保证每个编号恰好出现两次。
  


## 输出描述

输出一个整数，表示最大总分，不需要取模。答案可能超过 32 位整数范围，请使用 64 位整数类型。  


## 样例

### 样例 1
**输入**:
```
3
1 1 2 3 3 2
```

**输出**:
```
20
```

**说明**:  

先选择编号 1，清除长度为 2 的一段，再选择编号 2，清除剩下长度为 4 的一段，总分 2²+4²=20。  


### 样例 2
**输入**:
```
4
1 2 3 4 1 2 3 4
```

**输出**:
```
28
```

**说明**:  

先选择编号 2，清除 [2,3,4,1,2]，获得 25 分。剩余 [1,3,4] 各自清除，总分为 28。
