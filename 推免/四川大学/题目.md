## 1. 分数求和

**整理状态：√ 已整理**

**来源：** [GitHub 原始题面](https://github.com/winbeau/js-problemset/blob/main/schools/%E5%9B%9B%E5%B7%9D%E5%A4%A7%E5%AD%A6/001-%E5%88%86%E6%95%B0%E6%B1%82%E5%92%8C.md)

### 题目描述

有一分数序列：$2/1$、$3/2$、$5/3$、$8/5$、$13/8$、$21/13$、……

求出这个数列的前 $N$ 项之和，保留两位小数。

### 输入格式

输入一个正整数 $N$。

### 输出格式

输出数列前 $N$ 项的和，保留两位小数。

### 输入样例

```text
10
```

### 输出样例

```text
16.48
```

### 核对备注

原稿中的时间限制为 1000 ms、内存限制为 256 MB；公开原始题面未给出这两项平台信息，因此不作为通用题面要求。

### 参考代码

```cpp
#include <iostream>
#include <iomanip>

using namespace std;

int main() {
	// a、b 分别表示当前项的分母和分子，首项为 2 / 1。
	long double a = 1, b = 2;
	long double ans = 0;

	int n;
	cin >> n;

	while (n--) {
		// 当前项为 b / a；下一项的分子、分母分别为 a + b、b。
		ans += b / a;
		long double temp = a;
		a = b;
		b = temp + b;
	}

	// 按题意保留两位小数输出。
	cout << fixed << setprecision(2) << ans << endl;

	return 0;
}
```

## 2. 字符串编辑距离

**整理状态：√ 已整理**

**来源：** [洛谷 P2758 编辑距离](https://www.luogu.com.cn/problem/P2758)

### 题目描述

给定两个只包含小写字母的字符串 $A$ 和 $B$，求将字符串 $A$ 转换为字符串 $B$ 所需的最少字符操作次数。

允许使用以下三种操作：

1. 删除一个字符；
2. 插入一个字符；
3. 将一个字符修改为另一个字符。

### 输入格式

第一行输入字符串 $A$，第二行输入字符串 $B$。两个字符串的长度均小于 1000。

### 输出格式

输出将 $A$ 转换为 $B$ 所需的最少字符操作次数。

### 输入输出样例

当前原稿中保留的样例为：

输入：

```text
abcd
abc
```

输出：

```text
1
```

### 核对备注

原稿中的 `eat`、`tea` 是操作说明示例，不是官方输入样例；原稿的 256 MB 内存限制也可能是转载平台设置。洛谷官方页面当前样例为 `sfdqxbw`、`gfdgw`，输出为 `4`。

### 参考代码

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	string a, b;
	cin >> a >> b;

	int n = static_cast<int>(a.size());
	int m = static_cast<int>(b.size());
	vector<vector<int>> dp(n + 1, vector<int>(m + 1));

	// dp[i][j] 表示将 a 的前 i 个字符变成 b 的前 j 个字符的最少操作数。
	for (int i = 0; i <= n; ++i) {
		dp[i][0] = i;
	}
	for (int j = 0; j <= m; ++j) {
		dp[0][j] = j;
	}

	for (int i = 1; i <= n; ++i) {
		for (int j = 1; j <= m; ++j) {
			if (a[i - 1] == b[j - 1]) {
				dp[i][j] = dp[i - 1][j - 1];
			} else {
				dp[i][j] = min({
					dp[i - 1][j - 1], // 替换
					dp[i - 1][j],     // 删除
					dp[i][j - 1]      // 插入
				}) + 1;
			}
		}
	}

	cout << dp[n][m] << '\n';
	return 0;
}
```

液晶屏上，每个阿拉伯数字都可以显示成 5 行、3 列的点阵，其中 `X` 表示亮点，`.` 表示暗点。

现在给出数字位数和一串数字，要求输出这些数字在显示屏上的效果。每个数字之间有一列间隔。

### 输入格式

### 输出样例

```text
X.X...X...X...X.X.X.X...X.....X.X.X.X.X
X.X...X.XXX.XXX.XXX.XXX.XXX...X.XXX.XXX
X.X...X.X.....X...X...X.X.X...X.X.X...X
```

### 参考代码

```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 定义每个数字的 3x5 点阵表示
    vector<string> d[10] = {
        {"XXX", "X.X", "X.X", "X.X", "XXX"}, // 0
        {"..X", "..X", "..X", "..X", "..X"}, // 1
        {"XXX", "..X", "XXX", "X..", "XXX"}, // 2
        {"XXX", "..X", "XXX", "..X", "XXX"}, // 3
        {"X.X", "X.X", "XXX", "..X", "..X"}, // 4
        {"XXX", "X..", "XXX", "..X", "XXX"}, // 5
        {"XXX", "X..", "XXX", "X.X", "XXX"}, // 6
        {"XXX", "..X", "..X", "..X", "..X"}, // 7
        {"XXX", "X.X", "XXX", "X.X", "XXX"}, // 8
        {"XXX", "X.X", "XXX", "..X", "XXX"}, // 9
    };

    int n;
    string num;
    cin >> n >> num;

    for (int row = 0; row < 5; ++row) {
        for (int i = 0; i < n; ++i) {
            if (i > 0) cout << '.';
            cout << d[num[i] - '0'][row];
        }
        cout << '\n';
    }

    return 0;
}
```

## 6. 最大差值问题

**题面状态：√ 已整理**

**来源：** 用户提供的题面图片；高度匹配：[洛谷 B2153 求阶乘的和](https://www.luogu.com.cn/problem/B2153)。

### 题目描述

给定一个整数数组 `nums`，找出数组中两个元素的最大差值。要求较大元素的索引必须大于较小元素的索引，即满足 $i < j$，并最大化：

$$
nums[j]-nums[i]
$$

若数组长度小于 $2$，或者不存在满足条件的两个元素（例如数组严格非递增），则输出 `0`。

### 输入格式

第一行输入一个整数 $n$，表示数组长度。

第二行输入 $n$ 个整数，表示数组 `nums` 的元素。

### 数据范围

```text
1 <= n <= 100000
-10^9 < nums[i] < 10^9
```

### 输出格式

输出一个整数，表示满足 $i < j$ 条件的最大差值；若不存在则输出 `0`。

### 输入输出样例

输入：

```text
6
7 1 5 3 6 4
```

输出：

```text
5
```

### 题意示例

对于数组 `9 7 3 1`，虽然最大值为 `9`、最小值为 `1`，但 `9` 出现在 `1` 的左侧，不能组成合法答案，因此输出 `0`。

### 参考代码

```cpp
#include <bits/stdc++.h>

using namespace std;

int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int n;
	cin >> n;

	vector<long long> nums(n);
	for (long long &value : nums) {
		cin >> value;
	}

	if (n < 2) {
		cout << 0 << '\n';
		return 0;
	}

	long long minValue = nums[0];
	long long answer = 0;

	for (int i = 1; i < n; ++i) {
		// nums[i] 作为右端点，只能与此前出现的元素配对。
		answer = max(answer, nums[i] - minValue);
		minValue = min(minValue, nums[i]);
	}

	cout << answer << '\n';
	return 0;
}
```

## 7. 阶乘求和取模

**题面状态：√ 已整理**

**来源：** 用户提供的题面图片。

### 题目描述

给定一个正整数 $n$，计算：

$$
S=1!+2!+3!+\cdots+n!
$$

并将结果对 $1000000007$ 取模后输出。

### 数据范围

```text
1 <= n <= 100000
```

### 输入格式

输入一个正整数 $n$。

### 输出格式

输出 $S$ 对 $1000000007$ 取模后的结果。

### 输入输出样例

输入：

```text
5
```

输出：

```text
153
```

### 核心思路

直接分别计算每个阶乘会产生重复计算，时间复杂度为 $O(1+2+\cdots+n)=O(n^2)$。

利用递推关系：

$$
i!=(i-1)!\times i
$$

从 $1$ 到 $n$ 依次维护当前阶乘值 `factorial`，并将每一步的阶乘加入答案。每次乘法和加法后立即取模，避免数值过大。

### 复杂度

- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$

### 来源核对

- [洛谷 B2153 求阶乘的和](https://www.luogu.com.cn/problem/B2153)：题名、求和公式和样例 `n=5`、输出 `153` 完全匹配，但公开题面未显示本题图片中的取模要求和数据范围。
- [PTA 7-5 阶乘和（搜索线索）](https://www.baidu.com/s?wd=%22PTA%207-5%20%E9%98%B6%E4%B9%98%E5%92%8C%22)：求和公式和模数 `1000000007` 匹配，但其输入形式是多个整数，与图片中的单个 `n` 不完全一致；原检索到的博客直链当前返回 404。

因此，目前最稳妥的记录是：图片题与洛谷 B2153 高度匹配，模运算和数据范围可能来自川大夏令营版本或其他改编版本，暂不能确认完全同源。

### 参考代码

```cpp
#include <iostream>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    constexpr long long mod = 1000000007;

    int n;
    cin >> n;

    long long factorial = 1;
    long long answer = 0;

    for (int i = 1; i <= n; ++i) {
        factorial = factorial * i % mod;
        answer = (answer + factorial) % mod;
    }

    cout << answer << '\n';
    return 0;
}
```
