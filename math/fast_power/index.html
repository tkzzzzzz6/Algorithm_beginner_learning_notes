    快速幂 (Fast Power)¶

    原理¶

    计算 \(a^b\) 的朴素方法是循环乘 \(b\) 次, 复杂度 \(O(b)\)。快速幂利用二进制拆分:

    \[a^b = \prod_{i:\ b\text{ 的第 } i \text{ 位为 } 1} a^{2^i}\]

    每次循环将底数平方(\(a \to a^2 \to a^4 \to \cdots\)), 指数右移一位; 当指数当前位为 1 时, 把当前底数乘入答案。

    复杂度: 时间 \(O(\log b)\), 空间 \(O(1)\)。

    常见错误

    累乘器 res 的初始值必须是 1(乘法单位元), 而不是 base。 初始化为 base 会导致结果多乘一个 \(a\), 且 \(b=0\) 时返回 \(a\) 而非正确的 \(1\)。

    溢出

    不带模的快速幂在 \(a^b\) 较大时必然溢出 long long。 带模版本若 mod 接近 \(10^{18}\) 级别, 乘法需改为 (__int128)x * y % mod 防溢出。

    模板代码¶

    代码与仓库同步, 源文件: Template/math/fast_power.cpp

    /*
 * @Author: tkzzzzzz6

// 快速幂: base^power, O(log power)
// 注意: power = 0 时返回 1; 溢出请用带模版本或 __int128
long long fast_power(long long base, long long power) {
    long long res = 1;
    while (power > 0) {
        if (power & 1) res = res * base;
        base = base * base;
        power >>= 1;
    }
    return res;
}

// 带模快速幂: base^power % mod
// 若 mod 接近 1e18 级别, 将乘法改为 (__int128)a * b % mod 防溢出
long long fast_power(long long base, long long power, long long mod) {
    long long res = 1 % mod;
    base %= mod;
    while (power > 0) {
        if (power & 1) res = res * base % mod;
        base = base * base % mod;
        power >>= 1;
    }
    return res;
}
