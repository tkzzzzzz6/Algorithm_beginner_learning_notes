# Algorithm Learning Notes

面向 ICPC / CCPC 的算法学习笔记与竞赛模板库。

## 内容导航

| 分类 | 内容 | 模板代码 |
| --- | --- | --- |
| [数学](math/index.md) | 快速幂、逆元、exgcd、筛法、CRT | `Template/math/` |
| [数据结构](data_structure/index.md) | 树状数组、线段树、并查集、ST 表 | `Template/data_structure/` |
| [图论](graph/index.md) | 最短路、MST、网络流、Tarjan、树链剖分 | `Template/graph/` |
| [字符串](string/index.md) | KMP、AC 自动机、后缀数组、Manacher | `Template/string/` |
| [计算几何](geometry/index.md) | 点类、凸包、旋转卡壳 | `Template/geometry/` |
| [动态规划](dp/index.md) | 单调队列、斜率优化等经典优化 | `Template/dp/` |
| [杂项](misc/index.md) | 对拍、随机数、快读 | `Template/misc/` |

## 使用方式

- 每篇笔记包含: **原理讲解 → 复杂度分析 → 模板代码 → 例题**
- 模板代码引用自仓库 `Template/` 目录下的真实 `.cpp` 文件, 与代码保持同步
- 竞赛基础模板见仓库 `Template/base/base.cpp`
